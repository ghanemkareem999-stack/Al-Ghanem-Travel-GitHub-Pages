# New Madinah Hotel Map Research Note — 18 August 2026

It resolved a single labelled hotel property point at **Abi Sayeed Al Khudri Street, Behind Shariah Court, Madinah 41441** (plus code **FJ76+JM, Madinah**), consistent with the official property address.

This supports publishing an embedded property-location view and a persistent external Maps action. No practical named entrance gate or route from the property’s actual pedestrian access was reviewed, so the website must not publish a walking distance, duration, or named gate for this hotel yet.
