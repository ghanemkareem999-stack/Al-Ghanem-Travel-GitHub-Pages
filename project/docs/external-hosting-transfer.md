# نقل الغانم ترافل إلى استضافة Node.js خارجية

هذا الدليل يجهز **المصدر نفسه** للنشر على استضافة متوافقة مع Node.js وMySQL/TiDB، مثل خدمة ويب خارجية. لا يحتوي المستودع أو ملف ZIP على أسرار أو كلمات مرور أو مفاتيح فعلية، ولذلك تُدخل القيم من لوحة الاستضافة فقط. توضح وثائق Render أن متغيرات البيئة مخصصة لحماية مفاتيح API واتصالات قواعد البيانات من الإدراج في المصدر، وأن خدمة Express تقبل أوامر البناء والتشغيل الخاصة بالمشروع. [1] [2]

## ما يعمل بعد النقل وما يحتاج إعداداً خارجياً

| النطاق | الحالة بعد ضبط المتغيرات أدناه | الإجراء قبل الإطلاق الخارجي |
| --- | --- | --- |
| الصفحات العامة، الدليل، البحث، SEO، وروابط الاتصال | جاهز للبناء والتشغيل. | اضبط `DATABASE_URL` و`JWT_SECRET` و`CANONICAL_ORIGIN`، ثم اختبر الموقع عبر HTTPS. |
| نماذج الاستفسار والمراجعات | تعمل مع قاعدة MySQL/TiDB مهيأة. | طبّق المخططات أولاً؛ ويحتاج إشعار البريد إلى إعداد مزود البريد ومفتاحه. |
| صور الفنادق | يبقى مجلد `source/` خالياً من ملفات الصور الكبيرة ويحتفظ بمفاتيحها فقط. في حزمة التسليم الموحدة، توجد النسخة المادية في مجلد `media/` المجاور مع ملف المطابقة. | انسخ الصور المصرح بها إلى مخزن كائنات HTTPS، محافظاً على مفاتيح المسارات، ثم اضبط `ASSET_STORAGE_ORIGIN`. |
| الخريطة المضمنة | رابط الموقع والاتجاهات الخارجيان يظلان متاحين حتى عند تعذر المزود. | لتشغيل الخريطة المضمنة، وفّر تكامل خرائط خارجي متوافقاً؛ لا تنسخ مفاتيح المنصة الحالية. |
| لوحة المالك وتسجيل الدخول | تدفق الدخول الموجود يعتمد على خدمة OAuth الحالية. | استبدل OAuth بمزود مستقل أو أبقِ لوحة المالك غير متاحة خارجياً إلى أن يتم ذلك. الموقع العام لا يحتاج تسجيل الدخول. |

> لا تنشر موقعاً خارجياً بالاعتماد على متغيرات أو مفاتيح المنصة الحالية. هذه القيم ليست جزءاً من حزمة النقل ولا ينبغي نسخها من بيئة التشغيل الحالية.

## ملف النشر المرفق

يتضمن المشروع `render.yaml` كمثال جاهز لخدمة ويب واحدة. يحدد الإصدار 22 من Node.js عبر `.node-version`، ويبني التطبيق بالأمر التالي ثم يشغله:

```bash
corepack enable && pnpm install --frozen-lockfile && pnpm run build
pnpm start
```

الخادم يقرأ `PORT` الذي تمنحه الاستضافة ويربطه مباشرة، ويقدم فحصاً صحياً عبر `GET /healthz`. لا تغيّر المنصة قيمة `PORT` يدوياً؛ تستخدمه الخدمة تلقائياً.

## المتغيرات السرية في لوحة الاستضافة

أدخل هذه القيم من لوحة **Environment/Secrets**، ولا تضعها في Git أو داخل ملف ZIP أو في متغيرات البناء العامة. تؤكد وثائق Render أن لوحة Environment تحفظ القيم وتعيد نشر الخدمة عند تطبيقها. [1]

| المتغير | مطلوب | الاستخدام |
| --- | --- | --- |
| `NODE_ENV=production` | نعم | تشغيل نسخة الإنتاج. |
| `DATABASE_URL` | نعم | رابط MySQL أو TiDB المشفر بـ TLS عندما يفرض مزود القاعدة ذلك. |
| `JWT_SECRET` | نعم | قيمة عشوائية طويلة جديدة للجلسات. |
| `CANONICAL_ORIGIN` | نعم | رابط الخدمة النهائي، مثل `https://your-service.example`. |
| `ASSET_STORAGE_ORIGIN` | نعم إذا أردت الصور | أصل HTTPS لمخزن الصور الخارجي، مثل `https://assets.example.com/al-ghanem/`. |
| `RESEND_API_KEY` | عند تفعيل البريد | إرسال إشعارات الاستفسارات بعد إعداد المرسل. |
| `VITE_GA4_MEASUREMENT_ID` و`VITE_GTM_ID` و`VITE_META_PIXEL_ID` | اختياري | قياس تسويقي بعد موافقة الزائر. |

تتطلب الصور أن تكون مفاتيح التخزين متطابقة مع مسارات `/manus-storage/...` الموجودة في البيانات. مثال: المفتاح `hotels/pullman/exterior.webp` يصبح `https://assets.example.com/al-ghanem/hotels/pullman/exterior.webp` عند ضبط المثال أعلاه. يسمح ذلك للموقع بالاحتفاظ بروابط الصور الحالية مع تبديل الخلفية إلى مخزن خارجي.

## قاعدة البيانات والترحيل الآمن

أنشئ قاعدة MySQL/TiDB فارغة، انسخ رابطها إلى `DATABASE_URL` في أسرار الخدمة، ثم نفّذ التالي **مرة واحدة فقط** من Shell آمن متصل بنفس الأسرار:

```bash
pnpm install --frozen-lockfile
pnpm run db:push
```

ينشئ هذا الأمر ملفات الترحيل ويطبقها. قبل تشغيله على قاعدة تحتوي بيانات، خذ نسخة احتياطية، اقرأ ملفات الترحيل الناتجة، وتحقق من أن `DATABASE_URL` يشير إلى القاعدة الجديدة لا إلى قاعدة الإنتاج القائمة.

## خطوات النشر المختصرة

1. ارفع هذا المشروع إلى مستودع Git خاص أو استخدم الرفع المباشر في مزود Node.js.
2. أنشئ خدمة ويب Node.js من جذر المشروع. في Render اختر **New → Web Service** ثم استخدم أوامر البناء والتشغيل أعلاه؛ هذا يتوافق مع دليل Express الرسمي. [2]
3. أضف الأسرار في لوحة الخدمة. لا تستخدم خيار مزامنة ملف `.env` إلا من جهازك الخاص، ولا ترفعه إلى المستودع. [1]
4. جهّز قاعدة البيانات، ثم شغّل `pnpm run db:push` في بيئة آمنة.
5. انسخ الصور المصرح بها إلى مخزن HTTPS واضبط `ASSET_STORAGE_ORIGIN` قبل توجيه العملاء إلى الموقع الخارجي.
6. افتح `/healthz`، الصفحة الرئيسة، صفحة دليل الفنادق، وصفحة فندق تحتوي صوراً، ثم أرسل استفسار اختبار إلى بيئة الاختبار.
7. بعد نجاح الفحص، غيّر `CANONICAL_ORIGIN` إلى الدومين النهائي وأعد النشر.

## ما لا يجب نقله تلقائياً

لا تُنقل مفاتيح OAuth أو التخزين أو الخرائط الخاصة بالمنصة الحالية. كما لا تُنسخ `node_modules` أو `.env` أو `.git` أو سجلات التطوير أو مخرجات `dist` في مجلد المصدر. تقدم حزمة التسليم الموحدة الكود والوثائق والمخططات ونسخة وسائط منفصلة، بينما يبقى لكل استضافة قاعدة بياناتها وأسرارها ومخزن صورها ومزود دخولها الخاص.
