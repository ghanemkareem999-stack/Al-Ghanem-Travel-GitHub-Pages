# Hotel Image and Data Source Hierarchy

## Publication order

| Priority | Source class | Permitted use |
|---|---|---|
| 1 | Official hotel website or managing-company website | Primary source for the current operating name, property identity, and publishable hotel media after an exact property match. |
| 2 | Global online travel agencies, including Booking.com, Agoda, and Expedia | Cross-check hotel identity, rooms, and facilities; accept imagery only when the listing clearly identifies the same property and branch. |
| 3 | Google Travel and Google Maps | Verify the reviewed property point, exterior, and local context. User-generated imagery is review evidence only unless separately cleared for publication. |
| 4 | Authorised B2B bedbanks and wholesalers, including Hotelbeds, WebBeds, and TBO Holidays | Use structured descriptions and media only when Al Ghanem Travel has authorised access and the property match is explicit. |
| 5 | Tripadvisor and similar traveller-photo sources | Use as non-publishable reality-check evidence. Do not copy traveller photos into the public gallery without separate rights clearance. |

## Required checks before publication

An image must match the hotel name, city, and operating branch. It must not contain a visible third-party watermark, resolve to a different hotel identity, or rely only on a loosely similar search result. If the identity is uncertain, retain the candidate in review documentation rather than the public gallery.

## Data boundaries

Sources are used only for facts they explicitly support. A map pin does not prove room types; an OTA room card does not prove a named mosque gate; and an image search result does not by itself prove property ownership or current operation.

## Applied review examples — 2026-08-25

- **Nusk Al Eman Hotel:** An Arkaan Al Motamer property page was identified as a direct booking source, but its text could not be extracted automatically. It remains a discovery and cross-check source; the published exterior and lobby images were accepted only after the property identity aligned visually.
- **Sidrat Al Madinah:** Umrah Center identifies the property and provides a gallery/video-tour context, listed amenities, and check-in policy. It supports the identity cross-check but does not by itself authorize copying every hosted asset.
- **Taqwa Manazil Madina:** Planet of Hotels identifies the current name and Omar Bin Al Khattab Road location, and lists room types. This supports the identity and location cross-check for the matched exterior, corridor, and lobby images; it does not establish a named Haram-gate route.
