# سجل الصياغة العامة بست لغات

## الغرض والنطاق

يوثق هذا السجل اتجاه الصياغة المطبق في النسخ العامة لموقع **Al Ghanem Travel / الغانم ترافل**. وهو يربط العربية بالنصوص الإنجليزية والماليزية والأردية والإندونيسية والهندية بمستوى المعنى والنبرة، لا بترجمة كلمة مقابل كلمة. تخاطب العربية والأردية العميل بصيغة محترمة ومهنية، بينما تحافظ بقية اللغات على الوضوح والدفء المناسبين للشركات والمجموعات.

> **حدود المحتوى:** لا تتضمن الصياغة وعوداً بسعر أو توافر أو قرب أو زمن مشي أو مرافق ما لم تكن معلومة منشورة ومراجعة. كما لا تظهر على الواجهة عبارات عن حالة البحث الداخلي أو مراجعة المصادر أو السجلات التخطيطية.
