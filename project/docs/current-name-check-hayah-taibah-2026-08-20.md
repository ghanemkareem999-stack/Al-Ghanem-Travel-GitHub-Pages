# Hayah Taibah Hotel — identity and location check

**Review date:** 20 August 2026  
**Publication decision:** Do not add a new active location-only profile yet.

## Finding

Current lodging sources return the historic **Hayah Taibah Hotel** name. Google Maps currently distinguishes a **Hayah Taiba Hotel** listing on Saad ibn Abi Waqqas Street marked **permanently closed** from a differently titled active listing, **HAYAH AL TAIBA HOTEL MEDINA HOTEL**, at another point. The available evidence does not establish whether the active listing is a renamed successor or a distinct property.

## Editorial boundary

Do not merge, replace, or publish either identity until a first-party source or distinct current address establishes the relationship between the closed listing and the active similarly named listing.
