# Elaf Meshal Al Madinah — current identity check

**Review date:** 20 August 2026  
**Publication decision:** Do not add a new active profile under the Elaf Meshal name.

## Finding

Current third-party lodging sources retain several historic variants of **Elaf Meshal Al Madinah** and **Elaf Meshal Al Salam**, while current listings for the related property surfaces use names such as **Assaafa Golden Hotel** and **Meshal Hotel Madinah 2**. The current Elaf operator site does not provide a matching current property page. The name and specific current property relationship are not resolved safely.

## Editorial boundary

Do not publish the historic Elaf Meshal identity or merge it with Assaafa Golden / Meshal Hotel Madinah 2 until a current operator source or property point resolves the operating name.
