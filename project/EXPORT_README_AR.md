# حزمة مشروع الغانم ترافل

هذه الحزمة هي نسخة مصدرية قابلة للنقل من موقع **الغانم ترافل**. تضم واجهة React، الخادم، قاعدة البيانات وتعريفات الترحيل، صفحات SEO وSSR، المكوّنات متعددة اللغات، بيانات دليل فنادق المدينة، الاختبارات، والوثائق التشغيلية.

## ما تتضمنه الحزمة

| المحتوى | الموقع داخل الحزمة | الغرض |
|---|---|---|
| واجهة الموقع | `client/` | الصفحات والمكوّنات والتصميم واللغات الست. |
| خادم التطبيق | `server/` | واجهات التطبيق، SSR، منطق النماذج، وSEO. |
| مخطط وترحيلات قاعدة البيانات | `drizzle/` | تعريفات الجداول وملفات الترحيل. |
| بيانات الدليل | `shared/` و`client/src/lib/portfolio.ts` | بيانات فنادق المدينة وروابط الصور والموقع. |
| الاختبارات | ملفات `*.test.ts` | اختبارات الانحدار والدليل والتوافق. |
| الوثائق | `docs/` | سجلات التحقق وحدود الصور والمحتوى. |
| وسائط المصدر | `static-assets/` عند توفرها | نسخ الأصول التي استُخدمت للرفع إلى التخزين المُدار. |

## ما لا تتضمنه الحزمة

لا تتضمن الحزمة مفاتيح API أو كلمات المرور أو متغيرات البيئة أو ملفات `node_modules` أو مخرجات البناء المؤقتة أو سجلات التطوير. هذا مقصود لحماية الحسابات وتقليل حجم الملف. روابط صور الموقع المنشورة موجودة في الكود بصيغة `/manus-storage/...` وتبقى مرتبطة بخدمة التخزين للمشروع المنشور.

## التشغيل محلياً

> يلزم Node.js 22 أو أحدث، وpnpm، واتصال قاعدة بيانات متوافق مع إعدادات المشروع.

1. فك الضغط ثم افتح مجلد `al-ghanem-travel`.
2. ثبّت الاعتمادات عبر `pnpm install`.
3. انسخ قيم `RUN_CONFIGURATION_TEMPLATE.txt` إلى إعدادات استضافتك أو إلى ملف `.env` محلي خاص ثم أدخل قيم بيئتك. ستحتاج على الأقل إلى `DATABASE_URL` ومفاتيح المصادقة، مع إعدادات خدمة البريد والتخزين بحسب بيئتك. لا ترفع ملف `.env` أو تشاركه.
4. راجع `drizzle/schema.ts` ثم طبّق ملفات الترحيل الموجودة في `drizzle/migrations/` على قاعدة بياناتك.
5. شغّل المشروع محلياً عبر `pnpm dev`.

## الفحوص قبل النشر

نفّذ الأوامر التالية بعد ضبط البيئة:

```bash
pnpm check
pnpm test
pnpm build
```

بعد نجاح البناء يمكن تشغيل نسخة الإنتاج عبر:

```bash
pnpm start
```

للتطوير اليومي استخدم:

```bash
pnpm dev
```

## ملاحظات مهمة

يحظر دليل الفندق الشقق الفندقية من الصفحات العامة، ويحجب المسافات وأزمنة المشي والبوابات والتقييمات غير المراجعة. لا تُضف صوراً أو حقائق لفندق إلا بعد مطابقة الاسم والمبنى الفعليين. جميع تواصل العملاء يجب أن يبقى عبر الغانم ترافل فقط.
