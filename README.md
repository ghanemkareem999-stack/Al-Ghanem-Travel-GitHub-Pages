# Al Ghanem Travel — Public GitHub Pages Package

The root of this repository contains the static GitHub Pages preview. The complete source project, deployment files, documentation, and physical media are under `project/`.

GitHub Pages can serve the static preview but cannot run the Node/Express SSR server, database, admin dashboard, or server-side inquiry routes. For full production operation, use `project/README-DEPLOYMENT.md` and deploy the project to a Node-capable host with MySQL/TiDB and R2/S3.
